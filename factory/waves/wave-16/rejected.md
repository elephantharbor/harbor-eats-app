# Wave-16 rejected ideas

These ideas were considered and dropped, mostly because they come too close to one of the 185 existing meals or to another wave-16 pick.

| Idea | Why it was dropped |
|---|---|
| Pad thai | Too close to the existing peanut noodle stir-fry (sweet-salty peanut noodles). |
| Shrimp tacos | Too close to the existing fish tacos. |
| Mujaddara | Lentils, rice, and fried onions repeat koshari. |
| Thai green curry with tofu | A coconut curry with tofu repeats the red curry with kabocha. |
| Seafood paella | A saffron rice pan dish repeats the chorizo rice. |
| Shrimp étouffée | A roux-based Louisiana stew repeats the gumbo. |
| Beef stroganoff | Conflicts with the wave-16 mushroom stroganoff (same sauce and noodles). |
| Tonkatsu | A breaded pork cutlet overlaps the wave-16 schnitzel. |
| Bibimbap | The Korean cluster already has rice dishes (kimchi fried rice). Japchae fills a noodle gap instead. |
| Falafel | Chickpea meals are already crowded. |
| Coconut fish curries (Kerala, Thai) | Overlap the moqueca and the wave-16 amok. |
| Vietnamese shaking beef | Seared beef cubes with onion and tomato repeat lomo saltado. |
| Larb | Already in the catalog (Thai turkey larb lettuce wraps). The yum nua is a sliced-steak salad without toasted rice powder. |
| Greek shrimp saganaki | Shrimp in tomato with feta comes too close to the shrimp pasta and the tomato mussels. |
| Any chicken dish | Poultry is already well covered (23 meals, 19 with chicken in the title), so wave-16 uses none. |
| Long braises and slow-cooker meals | 25 meals already run over 90 minutes. Wave-16 stays at 35 to 53 minutes. |
