# S-05C.1 — Shopping display contract

**Status.** Accepted for the S-05C.1 runtime. No new grocery provider. Instacart stays disabled.

## Two readings of one line

| Surface | Quantity | Name |
|---|---|---|
| Native list | Spoken (`humanQuantity`) | Shopper’s capitals. An all-lowercase recipe name gains only a first capital. |
| Provider review | The same spoken quantity and the same name | Same rule |
| List image | Spoken unit, product noun kept in the name (`imageQuantity`) | Same name rule |
| Copy for my grocery app | Compact ASCII (`machineText`) | Stored words, including a countable inflection (`lime` / `limes`) |

Spoken means `tablespoon` and `teaspoon`. Compact means `tbsp` and `tsp`. `cup`, `oz`, `lb`, `dozen`, and `pack` use the same word on both readings. A count such as bananas is `3` on the image and `3 bananas` on the clipboard, so the image does not paint the noun twice.

`presentShopFaces` in `src/lib/shop-display.js` is the only place that decides this. `presentLine` and the provider projection read `humanQuantity`. The image painter reads `quantity_human`. `renderAppExport` writes `machineText` into the clipboard payload.

## Capitals

Matching and dedup still use the folded key. Display does not title-case every word.

- `Rao's` stays `Rao's`.
- `Yukon Gold potatoes` stays `Yukon Gold potatoes`.
- `yellow onions` on a human surface is `Yellow onions`. The clipboard line stays `2 lb yellow onions`, which is the stored recipe text.

## Package words

`dozen`, `pack`, and the other count-package words already in `PACKAGE_LEAD` are units. They are not part of the product name.

| Typed | Human quantity | Product | Clipboard |
|---|---|---|---|
| `1 dozen large eggs` | `1 dozen` | `large eggs` | `1 dozen large eggs` |
| `1 pack paper towels` | `1 pack` | `paper towels` | `1 pack paper towels` |

A row saved before this parser change, with the package word still inside an unparsed name, is split the same way at display time. `bag` still maps to the existing `package` unit when the parser sees it. This change does not invent a retailer package size, a count of 12, or any other conversion.

## Font

The list image waits up to 1.5 seconds for Plus Jakarta Sans (the UI face in `docs/FLAVORWEAVE-BRAND.md`). If the face does not load, the image still paints with Inter and the system fallbacks. A font miss is not a client error. The wordmark stays the SVG. It is not set in Plus Jakarta Sans or Inter.

## Check-offs

The in-store row reads “with check‑offs”, using a non-breaking hyphen so the word does not wrap mid-word on a narrow phone.
