## Reading the matrix

- **The only text path for both local chains is Instacart Shopping List "Paste items", and it is iPhone-only today** [IC-LIST]. Android and web users need an image path: Clementine on app or web, the Schnucks assistant, or Alexa for Shopping.
- **No consumer page anywhere documents how quantities or units are interpreted.** Every quantity-fidelity cell is Unverified except the native export and Kroger/Walmart API IDs. This is the main gap the human test has to close.
- **The image paths are documented for handwritten lists and recipe screenshots.** A typed, printed-style list image (what FlavorWeave renders) is plausible but Unverified on every path. Clementine's press release ("screenshot a digital one") comes closest [IC-CLEM-PR].
- **Retailer context.** Clementine and the Schnucks assistant both bind to a chosen store (documented). The Instacart Shopping List's store binding is undocumented.
- **AnyList organizes a list. It does not fill a retailer cart.** Its value is aisle categorization and sharing. It is not a checkout path.
- **Alexa for Shopping:** do not claim it fills a Whole Foods cart from an image. Only *voice* "add to my Whole Foods cart" is documented [AMZ-WFM]. The image feature documents "your cart" for *handwritten* lists [AMZ-AFS].
- **Walmart Sparky list import is not documented on any official page we could read.** The Walmart Affiliate API and ATC link are a separate developer path with affiliate terms.
